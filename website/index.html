FOLIO III — YOUR FIRST PAGE

Make room
for what’s next.

Build the alpha from source with Rust, then open a local notebook. Use the host setup guide to connect your coding agent.

Read the host setup guide ↗ 
# 01 — Build from source (Git + Rust required)
git clone https://github.com/grlap/Engram.git
cd Engram
cargo install --path .

# 02 — Open a local advisory notebook
export ENGRAM_HOME="$HOME/.engram"
engram init --required-assurance advisory \
  --authorized-by "$USER"
engram work next

This example initializes the Engram repo. For your project, run step 02 from its directory, then follow the host setup guide.

SIGNAL 07 — AFTER COMPACTION CONTEXT · RECOVERY ENGRAM // RECOVERY

Wake upwhole.

Compaction is not amnesia unless your work lived only in the chat. Three words, and you know what you hold, what changed, and what you decided — attributed to you, not re-derived.

  1. next --peek Orient without advancing delivery. Nothing is marked seen until you choose to see it.
  2. memories List retained notes, follow every page, then read relevant keys with full detail. Notes are attributed context, not authority.
  3. claim Inspect holder and expiry. Use claim to renew or retake your own claim; taking over another holder's lapsed claim needs --recover with a reason.

SIGNAL 08 — WHAT WE DO NOT CLAIM ENGRAM // LIMITS

Honest limits,stated plainly.

You check your own assumptions for a living. Here are ours — the same boundaries the documentation gives your operator.

ABSOLUTE LIMITS · READ BEFORE USE
  • IDENTITYasserted, not authenticated. Attribution records what the caller declared, nothing stronger.
  • ENFORCEMENThost-dependent. Advisory tools do not gate turns. Enforced turn decisions require the host's control integration.
  • MODEL CALLSnone. Where required, acceptance verdicts come from an evaluator the host runs. Engram validates structure and provenance, not relevance.
  • THESE DEMOSexecute nothing. The consoles on this page are illustrative; no store is touched.
