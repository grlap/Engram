FOLIO III — YOUR FIRST PAGE

Make room
for what’s next.

Build the alpha from source with Rust, then open a local notebook. Use the host setup guide to connect your coding agent.

Read the host setup guide ↗ 
# 01 — Build from source (Git + Rust required)
git clone https://github.com/grlap/Engram.git
cd Engram
cargo install --path .

# 02 — Open a local advisory notebook
export ENGRAM_HOME="$HOME/.engram"
engram init --required-assurance advisory \
  --authorized-by "$USER" --reason "Local advisory setup"
engram work next

This example initializes the Engram repo. For your project, run step 02 from its directory, then follow the host setup guide.
